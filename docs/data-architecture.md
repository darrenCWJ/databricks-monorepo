## How to use this document

- **As an engineer**, before starting work: scan Table 1 for similar
  projects, then check Table 2 to see who reads what you'll write.
- **As a reviewer**, before approving a project-creating MR: verify the
  rows are present and the cross-reads match `AGENTS.md` declarations.
- **As an auditor**, this is the canonical map. It's regenerated quarterly
  from the codebase and diffed against this file.
