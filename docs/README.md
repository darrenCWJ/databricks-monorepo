# docs/

All non-code documentation. Read first when joining a team or onboarding
an agent.

| Subfolder / file | What's in it |
|---|---|
| `data-architecture.md` | The big picture: every project, what it reads, what it writes. |
| `runbooks/` | Step-by-step how-tos: create a project, branch, release, etc. |
| `best-practices/` | Evergreen patterns: code style, data modelling, testing, secrets, performance, observability, security, cost. |
| `adr/` | Architecture Decision Records — why we chose what we chose. |
| `compliance/` | IM8, PDPA, SOC2 mapping documents. |

Keep it short. If a runbook is over ~400 lines, it's two runbooks.
